模板怎么用？
  • 前缀：如 maven-team-a- 一次匹配该团队全部仓库
  • 格式：如 npm 匹配所有 npm 仓库
  • 显式列表：逗号分隔精确指定
  • 套用是增量的：只写入模板覆盖的仓库，不影响用户其他仓库权限
  • 典型场景：新成员入职 → 建用户 → 套用团队模板 → 同步下发，三步完成
